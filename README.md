# General Blog

A modern blog built with Next.js 15, Tailwind CSS v4, and Supabase authentication.

## Features

- 🔐 **Authentication** - Login/Register with Supabase Auth
- 📝 **Blog Management** - Create, edit, delete articles
- 🛡️ **Protected Routes** - Admin panel with middleware protection
- ⚡ **Next.js 15** - App Router, Server Components, Server Actions

## Tech Stack

| Technology | Purpose |
|------------|---------|
| Next.js 16 | React framework |
| Tailwind CSS v4 | Styling |
| Supabase | Database & Authentication |
| TypeScript | Type safety |

## Getting Started

### Prerequisites

- Node.js 18+
- npm or yarn
- Supabase account

### Installation

1. Clone the repository
  ```bash
  git clone https://github.com/falouix-dlc/general-blog.git
  cd general-blog
```
2. Install dependencies
```bash
   npm install
```
3. Set up environment variables
```bash
   cp .env.example .env.local
```
